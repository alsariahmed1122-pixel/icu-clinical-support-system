# Intelligent Clinical Support System Based on Vital Signs

Educational Streamlit simulation for ICU-like monitoring, alerts, waveform visualization, and limited device-support simulation.

## Run locally

```bash
python -m pip install -r requirements.txt
python -m streamlit run src/app_streamlit.py
```

## Deploy on Streamlit Community Cloud

- Repository root: this folder
- Main file path: `src/app_streamlit.py`
- Python: 3.12 recommended
